# Where this folder comes from

This folder is the Claude Design handoff for the Vutric app and site, exported on 2026-11-17. It is a design reference,
not code, and [README.md](README.md) explains how to rebuild it.

- `Vutric App v4.dc.html` is the newest app design. It holds:
  - the phone screens;
  - the desktop catch scene;
  - 9 themes;
  - the throw prototype.

  Open it in a browser.
- `Vutric Site.dc.html` is the landing and design-system site.
- `refs/` holds the briefs the designer was given and three kinds of reference:
  - spike screenshots;
  - brand sheets;
  - desktop effect notes.
- The older iterations (v1–v3, "Full") are not copied, because the handoff README says to ignore them.

When copying, the personal name used as the sample device name was replaced with `STUDIO` / `Aziz`.

Stream W1 owns this folder ([workstreams.md](../../docs/workstreams.md)). Where the app improves on the design, the
improvement is recorded in a W1 ADR, and these files are left unchanged.
